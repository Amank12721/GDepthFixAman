# GDepthFixAman - Blender Addon

A Blender addon for fixing object depth offset relative to camera with automatic scaling correction.

## Features

- Adjust object depth offset towards/away from camera
- Automatic scale correction to maintain visual size
- Real-time preview with slider control
- Easy-to-use panel in 3D View sidebar

## Installation

1. Download `gdepthfixaman.py`
2. Open Blender
3. Go to Edit > Preferences > Add-ons
4. Click "Install" and select the downloaded file
5. Enable "GDepthFixAman" addon

## Usage

1. Select an object in 3D viewport
2. Open sidebar (press N)
3. Go to "GDepthFixAman" tab
4. Use "Depth Offset" slider to move object towards/away from camera
5. Scale automatically adjusts to maintain visual size
6. If you manually move the object, click "Set Current as Origin" to update the reference point

## Requirements

- Blender 2.80 or higher
